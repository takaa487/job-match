# 就活タイプ診断

就活生向けのタイプ診断と、診断結果から業界・企業を絞り込めるWebアプリです。

公開URL: https://job-match-gva5.onrender.com
（無料プランのため、しばらく使われていないと最初の表示に時間がかかります）

## 作ったきっかけ

大学の友達が「業種すら決まらない」と話していたのがきっかけです。話を聞くと、希望の給料や勤務地は決まっている人もいれば、何から考えればいいか分からない人もいて、状況は人によって違いました。
そこで、状況の違う人がそれぞれ使えるように作りました。

## できること

- 登録なしで就活タイプ診断を受けられる
- 診断結果から、向いている業界の企業一覧へそのまま進める
- 企業を業界・初任給・勤務地（全国6地域）で絞り込める。企業名や業種の言葉でも検索できる
- 企業名を入れると、AIがWebで調べてからESの下書きを作る。参考にしたページも表示し、登録されていない企業でも使える。作った下書きはログインして保存できる（Claude API。公開版は準備中）
- AIで条件に合う企業を探せる（公開版は準備中）

## 作るときに決めたこと

- ログインが必要だと使ってもらえないので、診断は登録なしで受けられるようにした
- 勤務地は、都道府県ではなく全国6地域で絞り込むようにした
- APIキーがないときはAIの機能を止めて「準備中」と表示するようにした（公開した時点でAPIの利用枠がなかったため）
- 企業のデータが消されても、利用者が保存したESは消えないようにした
- ESを作る機能を、AIがWebで調べて参考にしたページも出す方の1つにまとめた
- パスワードを表示できるようにした。メールで再設定できないので、確認欄は残した
- AIが探した企業は、データベースに保存しないようにした

## 開発の進め方

AI（Claude）に作りたいものを伝えてコードを書いてもらい、動かして思いどおりになるまで直してもらいながら作りました。
一通り動くようになったあと、AIにコードを見直してもらい、テストを今の動きに合わせて書き直し、使っていないコードを消し、データベースにもルール（空欄や重複を防ぐ）を入れました。push するたびに、テストとセキュリティのチェックが GitHub Actions で自動で動きます。

## 手元で動かす方法

```bash
bundle install
bin/rails db:prepare
bin/rails db:seed
bin/rails server
```

テストとチェックをまとめて動かすときは `bin/ci` を使います。

AIの機能を使うときは、`.env` に `ANTHROPIC_API_KEY` を入れます（このファイルはGitHubに上げません）。
